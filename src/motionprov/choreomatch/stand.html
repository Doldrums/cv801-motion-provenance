ChoreoMatch stand

A reimplementation of “What a Choreography Fingerprint Must Forget”: an encoder trained for choreography identity on AIST++, residual codes, and the retrieval engine (CRE). Search a query under an observation condition, see which references it matches, at which lag, and which cores voted.

Pick a query and search.
